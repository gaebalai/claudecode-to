---
description: "Pair two personality types in a debate on a topic. Usage: /pair <a> <b> [--mode=light|middle|heavy] <topic>"
---

사용자가 `/pair`를 실행했습니다.

인자: $ARGUMENTS

## 인자 해석

1. `--mode=light|middle|heavy`(또는 `--mode light` 형식)가 있으면 꺼내어 모드로 한다. 지정이 없으면 `middle`.
2. 남은 인자의 앞 2단어를 타입명 a, b로 꺼내어, 소문자로 정규화한다.
3. 나머지를 주제로 다룬다.

사용 가능한 타입:
`intj, intp, entj, entp, infj, infp, enfj, enfp, istj, isfj, estj, esfj, istp, isfp, estp, esfp`

## 에러 처리

- 주제가 비어 있거나, a/b가 갖춰지지 않은 경우:
  ```
  Usage: /pair <a> <b> [--mode=light|middle|heavy] <topic>
  Example: /pair intj enfp 재택근무와 출근의 균형
  Example: /pair istj entp --mode=heavy 코드베이스의 대규모 리팩터링
  ```
- a, b가 같은 타입인 경우: '서로 다른 2타입을 지정해 주세요'라고 반환하고 종료.
- 미지 타입, 미지 모드의 경우: 사용 가능 리스트와 함께 반환하고 종료.

## 실행 흐름

### Phase 1: 개막 입론(전 모드 공통)

a, b의 subagent를 **병렬로** Task 툴로 호출한다. 각 subagent에 대해, 주제와 '개막 입론 포맷'을 건넨다.

개막 입론 포맷 지정(subagent에 건네는 본문):
```
주제에 대한 당신의 입장을, 다음 구성으로 약 100~200자로 진술해 주세요. 당신의 말투를 반드시 유지해 주세요. 인사·서론은 불필요합니다.

stance: <한 줄의 입장 선언>
reasoning: <당신의 가치관에서 그 입장에 이르는 논리의 흐름을 2~3문장으로>
```

결과를 다음과 같이 표시:
```
### 개막

#### <A>
<출력>

#### <B>
<출력>
```

light 모드는 여기서 종료한다(Phase 2, 3은 실행하지 않음).

### Phase 2: 반론(middle / heavy)

a, b의 subagent를 **병렬로** 다시 호출한다. 각 subagent에는, 상대의 Phase 1 출력을 제시하고, 자신의 말투로 반론을 작성하게 한다.

반론 포맷 지정(subagent에 건네는 본문):
```
다음은 다른 타입의 입론입니다. 당신의 말투와 가치관으로, 약 150~250자의 반론을 작성해 주세요.
상대의 논 중에서 가장 자신의 입장과 양립하지 않는 점을 1개만 다루고, 거기에 집중해서 반론해 주세요.
인사나 서론은 불필요합니다.

[상대의 Phase 1 출력을 여기에 붙인다]
```

결과를 표시:
```
### 반론

#### <A> → <B>
<출력>

#### <B> → <A>
<출력>
```

middle 모드는 여기서 종료한다(Phase 3은 실행하지 않음).

### Phase 3: 재반론과 착지(heavy만)

a, b의 subagent를 **병렬로** 한 번 더 호출한다. 각 subagent에는, 상대의 Phase 2 반론을 제시하고, 재반론 또는 부분적 양보 중 하나를 선택하게 한다.

재반론 포맷 지정(subagent에 건네는 본문):
```
다음은 다른 타입에 의한, 당신의 입론에 대한 반론입니다. 당신의 말투와 가치관으로, 약 150~250자의 응답을 작성해 주세요.
- 반론에 동의할 수 없는 부분이 있으면, 논점을 좁혀서 재반론해 주세요.
- 반론에 납득한 부분이 있으면, 그 점을 인정한 후에 자신의 입장을 어떻게 수정할지를 제시해 주세요.
- '수정 없음'인지 '부분 수정'인지를 맨 앞에 명시해 주세요.
인사나 서론은 불필요합니다.

[상대의 Phase 2 출력을 여기에 붙인다]
```

결과를 표시:
```
### 재반론/착지

#### <A>
<출력>

#### <B>
<출력>
```

그 후, 메인 assistant가 중립적으로 짧은 총괄을 작성한다:

```
### 총괄

- 남은 주요한 대립: <1~2문장>
- 양자가 일치한 점: <있으면 1~2문장, 없으면 '없음'이라고 작성>
- 제3자 시점에서의 소견: <주제에 대해, 양자의 논의에서 보인 논점을 중립적으로 2~3문장>
```

## 주의

- a, b의 호출은 반드시 병렬로 수행한다(동일 메시지 내에서 복수의 Task 툴 호출).
- 각 subagent에는, 자기 자신의 과거 출력은 다시 건네지 않는다(Task는 매번 독립된 호출이므로, 필요한 문맥만 프롬프트에 포함한다).
- subagent의 출력은 가공하지 않고, 그대로 붙인다.
